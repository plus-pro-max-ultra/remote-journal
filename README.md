# 遠方誌未完成資料 / Work in progress

本分支只放尚未成型或仍待審閱的文章、研究、授權紀錄與必要圖片，不放正式網站副本，也不提供 Pages 網站。

- `review/ready-drafts/`：十五篇研究後改寫稿；名稱 ready-drafts 是原有資料夾名，不代表已批准發布。
- 第 017 期已完成、待正式發布批准的審閱頁保留於 `gh-pages`；此處只留該稿的研究紀錄，原 JSON 亦由封存標籤保留。
- `review/`：上述材料的來源、研究、編修與授權紀錄；歷史狀態只反映紀錄當時，不取代目前狀態。
- `assets/img/`：這些材料引用的必要圖片。
- `preservation-manifest.json`：從原 preview 精確版本複製的檔案與 SHA-256，供完整性核對。

完成的材料可移至 `gh-pages` 工作預覽；更新 `main` 正式網站仍須 MM 明確批准。沒有自動合併或自動正式發布。

目前 `gh-pages` 是直接編輯及顯示的網站版本。舊完整來源、模板、測試與網站產出已由 `archive/2026-11-05/preview-before-single-pages` 和 `archive/2026-11-05/gh-pages-before-single-pages` 標籤保留，不放到本分支充作另一份網站。
