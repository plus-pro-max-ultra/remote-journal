# 從作者手改學習：可追查的編輯紀錄

自2026-11-17開始補上固定驗收。依MM 11/4「持續觀察我做出修改的部分改善潤飾的水平」，不是另創改稿權限。

- 每筆保留版本／位置、前後原句及原訊息參照，分清「MM明說的偏好」「由一次手改推得的編輯假設」「輸入錯字／事實疑問」。不能把每個替換詞升成全站禁詞。
- [措辭對照](examples.md)是核實過的起始例，不宣稱已補齊全部歷史；新增手改在上架當次核對與整理，不留到下一篇才處理；備稿前仍可先評估。
- 每篇稿的editorial-learning-check.json須指出本次實際比較的gh版本、適用例與本篇位置、處理結果（已修改／原稿已有／不適用／待確認），附檢查前後稿件雜湊。沒用到的規則說明原因，不為湊數硬套。
- 查核在前，全文語言檢查在後；只填表不算完成。要再讀修改前後整段，確認主詞、具體動作、轉折、節奏與事實限制都成立。
- 機器只查紀錄完整、稿件未在檢查後變動，不能替代中文判斷，通過不代表已經學會或零缺點。
- 舊文保留MM原文，草稿僅在原有授權內改措辭；意思／事實有變仍先確認。安全與證據限制不因減少否定句刪除。
