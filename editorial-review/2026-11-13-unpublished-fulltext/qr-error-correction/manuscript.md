# 一張磨損的 QR code，手機究竟怎麼把它讀回來？

一張餐桌上的 QR code 被磨掉幾塊，手機還能讀出網址。另一張看起來只破了一點，卻怎麼掃都沒反應。若只知道「QR code 最多容錯 30%」，這兩種經驗像是互相矛盾。問題在於手機不是一次看懂整張圖：它先要找到碼、辨認格子，再從黑白排列取得資料，最後才有機會修正錯誤。容錯只保護這條流程中的一部分，不能保證每種破損都讀得回來。

## 一、工廠要的不是更大容量，而是少做幾次動作

原昌宏在 2019 年《Synthesiology》的[開發回顧](https://www.aist.go.jp/pdf/aist_e/synthesiology_e/vol12_no1/vol12_01_p19_p28.pdf)中說明，DENSO 在 1992 年開始研究新碼，當時製造現場為了管理更多資訊，有時須讀取約十種條碼，反覆掃描拖慢作業，也增加工作疲勞。這份開發者回顧，把起點放在當時現場反覆掃描的負擔。

把一維條碼堆高，或改成黑白方格，都有機會裝更多資料。團隊選擇方格形式，但新的困難是：掃描器看到的是整張影像，不知道哪裡才是碼；若每次都得在文字和圖案裡慢慢搜尋，容量增加可能換來更慢的作業。因此，讓碼容易被找到，和讓碼裝得更多同樣重要。

## 二、三個大方塊，是讓讀取器先找到地圖

QR code 三個角落的定位圖案，不是放商家資訊的地方。DENSO WAVE 說明，它們的黑白寬度比例為 1:1:3:1:1，團隊挑選這個在一般印刷品中少見的特徵，協助讀取器分辨碼與背景[1](#source-1)[5](#source-5)。辨認三個角的位置後，才有依據估計符號的方向、大小與傾斜。

找到外框還不夠。開發回顧另說明，交錯黑白的時序圖案協助推算各格中心，校正圖案則協助處理部分變形。這些部位像量尺與座標，不只是給人看的裝飾。若把嚴重破損的定位結構和資料格混成同一種損失，就會錯估後面校正碼能做的事。

這也說明「同樣遮住一小塊」為什麼不一定得到相同結果。遮住某些資料後，讀取器仍可能先建立座標；若連座標都不容易辨認，問題發生得比資料復原更早。

## 三、黑白格不是照片，而是有規則的資料序列

被讀取的黑白格要依規則轉成位元，再組成字碼。DENSO WAVE 的[容錯頁](https://www.qrcode.com/en/about/error_correction.html)將一個字碼定義為 8 個位元。因此，容錯談的計數單位不是「一格」，也不是印刷紙面上肉眼估計的缺角大小。

碼中還有一些看起來像雜訊的黑白變化，是刻意加入的遮罩處理。開發者回顧說明，這是為了避免黑白分布產生不利讀取的圖樣。它會依規則套用、也能依規則還原，不是在資料上隨便加密。想像相同資訊可以有不同的黑白外觀，就比較容易理解，QR code 的每一格並不各自對應一個固定的文字位置。

接下來才進入錯誤修正：即使影像取得的部分字碼有錯，只要仍在所用規格的能力範圍，額外資訊便有機會把原資料算回來。先辨識、再解碼、再校正，是概念上的層次；實際軟體可能反覆嘗試，不一定是一條只走一次的直線。

## 四、校正資訊怎麼恢復缺掉的資料

QR code 使用里德所羅門碼。直覺上，它不像把同一份網址完整影印三遍，而是增加一組與原資料有數學關係的值；讀到的內容若不符合這些關係，解碼器便能在能力範圍內判斷並修正錯誤。DENSO 的說明也指出，校正資訊本身同樣可能弄髒，所以復原率要以全部字碼計算。

官方給的示意例是：100 個原資料字碼，加上 100 個校正字碼，共 200 個，最多可修正其中 50 個字碼；50 除以 200 是 25%。在這個示意配置中，額外的校正資訊也計入總量；所以可修正 50 個字碼，對應的是 25%，而非 50%。

較大的碼還會將資料分塊、各自產生校正字碼，再依規格交錯排列。[Thonky 的技術教學](https://www.thonky.com/qr-code-tutorial/structure-final-message)用版本 5、Q 級的實例逐步示範這個過程。這表示錯誤不只看總數，也得看分散到哪些區塊；不能把某一區塊沒用到的能力，想成能無限制借給另一塊。

## 五、百分之三十，究竟是哪個百分之三十？

DENSO 的[規格頁](https://www.qrcode.com/en/about/standards.html)用字碼明列四個等級：L 約 7%、M 約 15%、Q 約 25%、H 約 30%。同樣原資料，保留更多校正資訊就需要更多空間，或在固定尺寸下減少可放內容。選最高容錯，不是沒有代價。

開發者 2019 年文章曾以「表面積」作較簡化的說明；現行官方細部規格則明寫 codewords。依後者的「字碼」定義，不把它轉寫成整張碼可任意遮住的面積比例。定位、格子讀取、格式及分塊都會影響是否成功，手機鏡頭、對焦與印刷品質也不是增加校正字碼就能全部解決。

中央放了商標仍能掃，顯示那個設計在當次讀取條件下仍有餘裕。換一支手機、換一種光線，或再累積污損，都可能改變結果。

## 六、開放讓它通用，容錯卻不替內容作保

技術之外，DENSO 公開規格並對符合標準的 QR code 不行使特定專利權；2000 年 6 月，QR code 成為 ISO 國際標準。開發者回顧也很坦白：碼的規格開放，讀取設備及辨識技術仍是商業的一部分。共通格式讓更多人採用，設備與服務則保留了商業空間。

最後要分清楚另一種正確性：校正碼協助恢復「這張碼原本記錄的內容」，沒有驗證那個網址的主人、交易對象或承諾是否可信。即使每個字碼都精確讀回，內容仍可能不值得信任。耐髒、快速、可通用，分別解決了傳遞工具的問題；我們把它用來付錢或開啟網頁時，仍多了一個工具本身沒有回答的身分問題。

## 延伸思考

生活中有哪些東西，必須容許我們弄錯、忘記或磨損一點，才真的好用？想起一項你希望更寬容的規則或服務：你願意為這份餘裕多付出什麼，又希望它在哪裡明確畫出界線？
